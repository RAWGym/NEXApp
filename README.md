# NEX: Digital Asset Exchange

Telegram Mini App и PWA для iPhone: курсы и графики, заявки на обмен с комиссией 3%, история, личный кабинет с верификацией, документы. Оператор управляет заявками в Telegram-боте.

## Как это работает

1. Клиент выбирает валюты и сумму, видит итог с комиссией 3% и отправляет заявку.
2. Бот присылает оператору заявку с кнопками «Принять» и «Отклонить».
3. После «Принять» оператор получает контакт клиента, клиент получает уведомление.
4. Стороны проводят обмен в Telegram, оператор нажимает «Подтвердить обмен».
5. В приложении клиента заявка становится «Выполнен».

Верификация: клиент заполняет анкету и прикладывает фото документа и селфи, оператор получает их в боте и нажимает «Одобрить». В профиле появляется отметка «Подтверждён».

## Состав

- `web/`: фронтенд (React + Vite + TypeScript). Работает внутри Telegram и как PWA.
- `supabase/functions/nex/`: бэкенд (Supabase Edge Function): API приложения, вебхук бота, уведомления о курсе.
- `supabase/migrations/`: схема базы.

## Команды оператора в боте

- `/orders`: активные заявки
- `/kyc`: анкеты на проверке
- `/stats`: статистика за 30 дней
- `/block ID`, `/unblock ID`: блокировка пользователя

## Настройки

Публичные настройки фронтенда: `web/.env.production` (адрес API, имя бота, поддержка, реквизиты для документов `VITE_LEGAL_NAME`, `VITE_COUNTRY`, `VITE_EMAIL`).

Лимиты и комиссия: `web/src/config.ts` и константы вверху `supabase/functions/nex/index.ts` (их нужно менять в обоих местах).

Секреты бэкенда (`BOT_TOKEN`, `ADMIN_IDS`, `WEBAPP_URL`, `CRON_SECRET`) хранятся в строке `config` таблицы `kv` в Supabase (таблица закрыта RLS) или в секретах Edge Function.

## Локальный запуск

```bash
cd web
npm install
npm run dev
```

Без `VITE_API_URL` приложение запускается в демо-режиме: данные хранятся в браузере, а действия оператора можно имитировать кнопками на экране заявки.
